# Cradle to the Grave map artwork

Original PNGs copied unchanged from the user-owned C2G project, with permission to use them in Frenemies backgrounds. Artwork remains COLTRAN Studios property; inclusion does not grant an independent asset redistribution license.

Source: packages/com.coltranstudios.c2g.content/Runtime/Art/2D/Environment (Map_zone1 files) and UI/setz01_rock.PNG (renamed rock.png).

The runtime composes these assets in public/environment-scenes.js. No external services or image processing dependencies are required. Layout anchors use the existing side-on battle camera, with the actor foot plane at 76% of canvas height. Existing forest and ruins IDs are retained so saved selections work.
